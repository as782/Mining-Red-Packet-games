# 道具交互规范

矿洞夺宝 v3 所有道具（现在的和以后加的）怎么出现、怎么用、怎么说。2026-11-11 用户在 Stage 上看过以后定的方向：
道具操作用弹窗（B）、按钮一律叫“使用”、进入选格子这一步时顶上有说明和取消、引导弹窗左边有“不再提示”、
顶上的步骤条有问号能再看引导。2026-11-12 又定了（`V3_ITEMS.md` §13）：引导只弹第一次，点“知道了”收进问号；
工具条一格只有一种激活态；说明只写玩家用得上的；最后一下先问一句。规则都在这里，`V3_ITEMS.md` §5 只写现在做成了什么样。

## 1. 原则

1. **操作留在手指所在的地方。** 说明可以放在别处，按钮不行：确认在弹窗里，按钮挨着说明；对准格子的确认就是在同一处再点一次。
2. **一样的事一个样子。** 同一类道具走同一个流程，手机和电脑走同一个流程，只有“预览”这一下不同（手机点一下，电脑指着）。
3. **不占地方。** 工具条浮在地图上，只有自己那一块；不在工具条旁边长气泡；提示盖在地图上，不挤布局。
4. **随时能退。** 每一步都有“取消”，而且不止一种退法（取消按钮、再点那一格、Esc、右键、点遮罩）。
5. **教会了就别再拦。** 引导只在第一次弹，点“知道了”就收进步骤条的问号，问号永远能再打开。
6. **只说玩家用得上的。** 看得见的（剩几次、还有几个、用了少一个）不用字说；只说会怎样，和拿不准又影响决定的事。

## 2. 道具分五类

每样道具只属于一类，类决定流程；名字、图标、数量、说明这些是填进去的。

| 类 | 是什么 | 现在的道具 | 点工具条以后 |
|---|---|---|---|
| **瞄准** | 要在地图上选一个位置才能用 | 附魔镐（横、竖、十字）、望远镜、火把、试炼钥匙 | 第一次：引导弹窗 → 选位置这一步；以后直接选位置 |
| **即用** | 不用选位置，用了就生效 | 急迫药水、藏宝图 | 确认弹窗 |
| **抉择** | 用之前要看清后果或挑一样 | 末影箱（存一半、毁一半）、附魔台（二选一） | 专属弹窗 |
| **被动** | 自己生效，不用点 | 盾牌、煤炭、木棍、中毒 | 说明弹窗 |
| **基础** | 平时的挖 | 镐子 | 拿着别的道具时是“取消”；平时是说明弹窗 |

新道具先决定是哪一类；哪一类都不像的，先改这份规范再做。

## 3. 三块界面，各管一件事

### 3.1 工具条：只是入口

- 浮在地图上（竖着的画面左下、横着的左边居中），挖卡时镜头让开它那一条。放不下时在自己那块里滚，两头渐隐、有箭头。
- 一格的样子：图标、右下角的像素数字；附魔镐左上角是形状小图；煤炭、木棍是进度条。
- 一格只有四种样子：
  - **激活**：手上拿着的那一件，金边、变大（48 → 58，图标跟着放大），一次只有一格。贴着靠边的那一侧往外长、探出托盘（工具条在下面时往上，在左边时往右），旁边的格子让开；托盘不跟着变大，别的格子都贴着靠边的那一侧。什么都没拿时是镐子；拿起火把，镐子缩回、火把变大，放下再换回来。开着弹窗不算，弹窗下面整条是暗的。
  - **平常**。
  - **没有**：一直摆着但现在没有的（火把），灰的，写 0。
  - **不能用**：已领取、暂停，整条变淡。
- 镐子身上的中毒、急迫、蜘蛛网标记是效果，叠在任何样子上。地图上预览格子的颜色另算（望远镜是青的）。
- 点一下就是开始这件道具的流程，见第 4 节。工具条旁边不出任何气泡、菜单。

### 3.2 弹窗：说明和决定

所有道具弹窗一个版式：

```
┌──────────────────────────────┐
│ [图标] 名字            还有 N 个 │  ← 数量在右上，单位见 §5
│        （可选）小图演示          │  ← 形状、火把照亮哪 4 格这类一眼看懂的
│ 一句：它会怎样。                 │
│ 小字：拿不准又影响决定的事，最多一句 │
│ 小字：怎么点（只有瞄准类有）。     │
│                 取消   知道了 │  ← 主按钮在最右
└──────────────────────────────┘
```

- 按钮从右往左：主按钮、次按钮（取消）。主按钮会花掉东西的叫“使用”；看完说明、接着做刚才要做的事、什么都不花掉的叫“知道了”（只有说明的弹窗是关掉，瞄准类第一次的引导是进入选位置，问号打开的是回到选位置）。
- 写什么：名字、数量在标题行，正文不再说；看得见的数和它们怎么变不用字说（不写“用掉 1 次”“不花机会”）；弹窗里有图的、用了看得到的不用字说。
- 关掉：取消、点遮罩、Esc，都等于什么都没做。
- 一次只有一层；弹窗里要再打开别的，叠一层新的（和红包站一样）。

### 3.3 顶上一行：步骤条和通知

地图顶上正中一个位置，盖在地图上（不挤布局），一次只显示一条，优先级从高到低：

1. **苦力怕来了**（紧急，倒数）。
2. **步骤条**：在选位置这一步时一直在。`[图标] 名字 · 一句话说现在该做什么   [?] [取消]`
   - 没预览时说怎么点（“点一个挖开的格子”“点宝库”）。
   - 预览以后说这一下会怎样（“插在 C3，照亮周围 9 格”“挖开 3 格，跳过 1 格挖过的”），能用时后面接“再点一下确认”（手机）或“点一下确认”（电脑）；不能用时说为什么（“这里已经有火把了”）。
   - `?` 再打开这件道具的引导弹窗：从问号里长出来，只有“知道了”，关掉（知道了、遮罩、Esc）收回问号，回到这一步；`取消` 退出这一步。
   - 手机和电脑一样；电脑上跟着指针的小提示在这一步不出，免得说两遍。
3. **通知**：和手上操作无关的事（末影箱存好了、地图长了新卡这类）。要留着看的带“知道了”，不自己消失。

## 4. 每一类的流程

### 瞄准

```
点工具条上的它
 ├─ 第一次：引导弹窗  [取消] [知道了]
 │     ├─ 知道了：记住（这台设备、这一种），进入选位置；弹窗收进步骤条的问号
 │     └─ 取消 / 遮罩 / Esc：原地关掉，不记住，下次还弹
 └─ 学过：直接进入选位置

选位置（步骤条在顶上，那一格金边）
 ├─ 手机：点一下预览，同一处再点一次确认；点别处预览挪过去
 ├─ 电脑：指着预览，点一下确认；指针是箭头带这件道具
 ├─ 确认成功：用掉一个，退出这一步
 ├─ 确认不成（位置不对、被别人先挖了）：说为什么，留在这一步
 └─ 退出：步骤条的取消、再点工具条上的它、点镐子、Esc、右键、领取、这件用完了
```

- 拖动、双指永远是挪地图和缩放，不算点。
- 不在挖卡这一级时，进入选位置会先飞到当前卡。
- 三种附魔镐算一种。以前选过“不再提示”的算学过。
- 收进问号（`guideFly.ts`）：字和按钮先淡掉，外框先原地收到一半（先快后慢），再先慢后快飞到问号上（和煤炭、木棍流进火把格同一条曲线），中途沿飞的方向稍拉长，颜色变成问号按钮的颜色，共 380 ms；落到时问号果冻弹一下、金边亮约 1 秒、一声 pop。飞的是不接收点击的影子，地图马上能点。没有问号（苦力怕挡着顶上）就原地淡掉；减少动态时不飞不弹，只让问号亮一会儿。

### 最后一下

这一下挖完，这一局就挖不动了（镐子、附魔镐只剩这一下，也没有附魔台），手里还有钥匙、望远镜、火把、藏宝图没用：先弹“最后一下了”，列出它们，`[俺去瞅瞅] [这就是最后一舞]`。俺去瞅瞅（遮罩、Esc 也是）不挖，工具条上那几格扫一道光、弹一下；最后一舞照样挖。药水、末影箱不提醒。还有附魔镐时镐子的最后一次不算最后一下，不问。

### 即用

点工具条 → 确认弹窗 `[取消] [使用]` → 使用以后在顶上或道具本身上看得到效果（药水：镐子上挂药水标记；藏宝图：镜头飞过去，那一格亮）。每次都问：用掉就没了，确认这一下是防手滑。

### 抉择

点工具条 → 专属弹窗：先把后果摆出来（末影箱：手上 → 存进 / 毁掉），或者把选项做成卡片（附魔台两种形状），按钮仍是 `[取消] [使用]`，选卡片就是使用。

### 被动

点工具条 → 说明弹窗 `[知道了]`。被动道具起作用时（盾牌挡下、中毒扣分、合成火把）在格子或工具条上有动静，必要时顶上一条通知。

### 基础（镐子）

在选位置这一步时点它就是取消；平时点它是说明弹窗（还剩几次机会、挖掘间隔）。

## 5. 用词

| 场合 | 用 | 不用 |
|---|---|---|
| 道具弹窗的主按钮 | 使用 | 拿起来、喝下、打开、存一半毁一半 |
| 退出、不做 | 取消 | 放下、放回去、先不挑 |
| 没领的钱 | 待领取 | 手上、手里、矿洞里的奖励、分 |
| 看完说明、什么都不花的按钮 | 知道了 | 好的、确定 |
| 选位置的两下 | 预览、确认（只在说明文字里）；“点…预览，再点一下确认” | 放上去看看、才用、同一处再点一次确认 |
| 镐子能挖几次 | 还能挖 N 次、镐子用完了、能挖的都用完了、镐子 +3 次 | 机会 |
| 数量 | 还有 N 个／把／瓶／张；盾牌 N/3 面；煤炭、木棍 N 个（第 1 版 N/2）；中毒还有 N 次；附魔镐还能用 N 次 | |

句子写完整、用常见的说法（见红包站的 plain-ui-copy 规则）；名字就是物品名，不加“道具”两字。

## 6. 新道具清单

加一样道具时，依次填这些；界面（工具条一格、弹窗、步骤条、指针）由类自动给出，不另画：

1. **类**：瞄准、即用、抉择、被动里的哪一种。
2. **名字、图标**：Minecraft 原版物品名和贴图（来源记进 `docs/MINECRAFT_ASSETS.md`）。
3. **数量的单位**，见 §5。
4. **说明**：一两句它做什么，写进道具登记表（`page/frontend/v3/src/items.ts` 的 `aboutSlot`，瞄准类还有 `AIM_WHAT`、`AIM_TARGET`）。
5. 瞄准类还要：**点什么**（格子、缝、宝库……）、**预览盖住哪几格、能不能用、说一句什么**（`aim.ts` 的 `aimInfo`），和可选的小图演示。
6. 即用、抉择类还要：**用了以后看得到什么**。
7. **从哪里来**（哪种格子、哪种区块、什么概率）和**游戏站的接口**（`POST /v3/api/use` 的 `item`），写进 `V3_ITEMS.md` §3、§4。
8. 检查一遍 §1 的五条：按钮挨着说明吗？手机电脑一样吗？占地方了吗？每一步能退吗？引导能跳过也能再打开吗？
